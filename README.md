# StoreForYou

Каталог одежды и кроссовок: поиск, фильтры, избранное и связь с продавцом в Telegram.

## Локальный просмотр

Скачайте репозиторий и в папке с `index.html` запустите:

```sh
python3 -m http.server 8000
````

Откройте [http://localhost:8000](http://localhost:8000/).

`products.js` содержит данные каталога, `assets/` — фотографии. Сборка и установка зависимостей не нужны.
